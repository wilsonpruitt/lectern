Lectern

A preacher’s workbench over the church year. Three spatial models for the Sunday workbench — same real Proper 23 (A) content, arranged three ways. Click each; flip the Semicontinuous / Complementary track and the A·B·C call-to-worship registers to feel how each holds up.

Layout A

Pinned readings + tool tabs

The day’s readings fixed in a left rail, always in view; a tab bar moves between tools. Focused, one tool at a time — the IDE / email model.

 Layout B

Dashboard card-grid

Every tool a tile in a two-column grid — glanceable summaries you drill into. Overview-first; the Sunday “home.”

 Layout C

Column board

Each tool its own column; scan horizontally across readings · sermons · hymns · liturgy. Scales by adding columns as tools grow.
